# PDF fonts

The two TrueType files are subsets of Noto Sans SC at weights 400 and 600. They include the alphabets, symbols and Chinese characters used by the report and model interpretations. Additional subscript and superscript numerals use the digit outlines from the same font. The PDF embeds the characters used in each document.

The reserved font name and licensing terms are recorded in [OFL.txt](OFL.txt). [Noto Sans SC upstream](https://github.com/google/fonts/tree/main/ofl/notosanssc).
